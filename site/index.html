placeswiki is an open dataset of historical places and landmarks — coordinates, descriptions and photographs — assembled from Wikidata and Wikimedia Commons, and served in the protocol of the Google Places API.

Places APIs are metered twice. Each lookup is billed, and the terms forbid keeping what you fetched, so the cost never falls as a product grows. The same facts — a church, its coordinate, forty photographs of it — are already published by volunteers under licences that permit redistribution.

placeswiki builds that database once, stores it in a single SQLite file, and answers the Google endpoints from it. A client changes one base URL and keeps its parser. Everything runs on hardware its operator controls; no account, key or per-request fee is involved.

Using it

Run the server, point a client at it, keep the rest of the code.

docker build -t placeswiki .
docker run -d -p 8080:8080 -v "$PWD/data:/data" placeswiki
const BASE = "https://places.yourdomain.com";
await fetch(`${BASE}/v1/places:searchNearby`, {
  method: "POST",
  headers: { "X-Goog-FieldMask": "places.id,places.displayName,places.location" },
  body: JSON.stringify({
    locationRestriction: { circle: { center: { latitude: 46.05, longitude: 14.5 }, radius: 500 } }
  })
});

The endpoints are POST /v1/places:searchNearby, POST /v1/places:searchText and GET /v1/places/{id}. Field masks, nested paths and error envelopes behave as they do upstream. Guides: integration, deployment, API.

The data

Wikidata records about 2.2 million heritage-designated places with coordinates. Each one is staged, enriched with its Commons photograph, and given a stable identifier of the form wc:Q10285; Google place identifiers are attached only as an optional join key, never as the primary identity.

Photographs are scored rather than picked at random: resolution, licence, attribution and whether the community chose it as the lead image. The reasons are stored beside the score, so a client can explain its choice.

A 500-place sample from Slovenia ships with every release: 940 KB of database, 377 photographs, 268 KB slimmed for serving.

Contributing

The dataset is only as good as the volunteers behind it. Corrections belong upstream: a wrong coordinate is wrong in Wikidata, a missing author is missing on Commons. The tool lists what is absent — placeswiki gaps — with links to the items that need work.

Code contributions follow the contributing guide. Tests run offline, no scraper is accepted, and the project never writes to Wikimedia on its own.
